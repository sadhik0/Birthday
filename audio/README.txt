OPTIONAL MUSIC
==============

Put a song you have the right to use in this folder and name it:

  birthday-song.mp3

Then reload the page. The small music button at the bottom-right becomes active.
Music never starts by itself; the visitor has to press the button.

If this file is missing, the button stays dimmed and nothing breaks.

To use another file name or path, change `musicSrc` in the CONFIG block at the
top of script.js.
